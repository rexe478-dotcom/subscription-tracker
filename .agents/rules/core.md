# Core Workspace Rules

Follow `AGENTS.md` and the documents in `docs/`. Do not implement Gmail, payments, household sharing, bank linking or automatic cancellation in v1. Never sum unlike currencies. Never expose privileged secrets. Enforce RLS. No deployments or paid resources without approval. Use the approved design tokens and avoid generic AI-template styling. Work in milestones and run tests before claiming completion.
