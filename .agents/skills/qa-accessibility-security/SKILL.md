# QA Accessibility Security Skill

1. Read the acceptance criteria and relevant implementation docs.
2. Test recurrence edge cases, currencies, RLS isolation and notification idempotency.
3. Audit keyboard, screen reader, contrast, focus, reduced motion and touch targets.
4. Inspect mobile, tablet and desktop layouts.
5. Check secrets, URL validation, authorization and dependency risks.
6. Report severity, reproduction steps and evidence.
7. Do not approve a milestone with unresolved critical or high-severity defects.
