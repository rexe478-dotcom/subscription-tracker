# PWA Engineering Skill

1. Read `docs/PWA_AND_DEPLOYMENT.md`.
2. Implement manifest, icons, service worker, HTTPS deployment assumptions and route fallback.
3. Keep offline claims honest; show when data is not synced.
4. Handle app updates without losing active user work.
5. Provide iOS Home Screen install guidance and Android/desktop install support.
6. Test real devices and browser support; do not assume identical Web Push behaviour.
