# Mascot and Brand Assets Skill

1. Read `docs/MASCOT_AND_BRAND_ASSETS.md` and `docs/DESIGN_SYSTEM.md`.
2. Develop a distinctive character concept and silhouette before creating many assets.
3. Present a concept sheet for approval before final production.
4. Keep vector source, export variants and provenance/licensing records.
5. Design a small set of purposeful poses for onboarding and product states.
6. If animation is approved, prefer state-based Rive with static and reduced-motion fallbacks.
7. Never imitate an existing app mascot or invent provider logos.
