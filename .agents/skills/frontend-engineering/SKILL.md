# Frontend Engineering Skill

1. Read `docs/ARCHITECTURE.md`, `docs/DESIGN_SYSTEM.md` and relevant feature specs.
2. Use React + TypeScript + Vite and existing project conventions.
3. Keep components cohesive; separate feature UI, data access and shared primitives.
4. Validate forms and handle loading, empty, error, success and offline states.
5. Keep privileged secrets out of client code.
6. Avoid unnecessary dependencies and global state.
7. Add tests for important interactions and edge cases.
8. Run lint, typecheck, tests and production build.
