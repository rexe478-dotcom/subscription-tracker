# UI Design System Skill

1. Read `docs/DESIGN_SYSTEM.md` and `docs/UI_UX_AND_ONBOARDING.md`.
2. Use the documented tokens; do not invent new colours ad hoc.
3. Build a coherent component system and responsive page layouts.
4. Prefer clarity, whitespace, typography and useful grouping over decorative cards.
5. Use Lucide consistently; never use emoji as UI iconography.
6. Design loading, empty, error, success, offline and permission-denied states.
7. Check keyboard access, contrast, focus, reduced motion and touch target size.
8. Capture mobile and desktop screenshots and compare against the spec.
